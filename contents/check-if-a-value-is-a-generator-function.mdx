title: Check if a value is a generator function

**JavaScript version**

```js isGeneratorFunction.js
const isGeneratorFunction = (v) =>
    ['[object GeneratorFunction]', '[object AsyncGeneratorFunction]'].includes(Object.prototype.toString.call(v));
```

**Examples**

```js examples.js
isGeneratorFunction(function () {}); // false
isGeneratorFunction(function* () {}); // true
isGeneratorFunction(async function* () {}); // true
```
