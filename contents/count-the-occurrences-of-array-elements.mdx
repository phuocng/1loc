**JavaScript version**

```js countOccurrences.js
const countOccurrences = (arr) => arr.reduce((prev, curr) => ((prev[curr] = (prev[curr] || 0) + 1), prev), Object.create(null));
```

**TypeScript version**

```ts countOccurrences.ts
const countOccurrences = <T extends string | number,>(arr: T[]): Record<T, number> => (
    arr.reduce((prev, curr) => ((prev[curr] = (prev[curr] || 0) + 1), prev), Object.create(null) as Record<T, number>)
);
```

**Examples**

```js examples.js
countOccurrences([2, 1, 3, 3, 2, 3]); // { '1': 1, '2': 2, '3': 3 }
countOccurrences(['a', 'b', 'a', 'c', 'a', 'b']); // { 'a': 3, 'b': 2, 'c': 1 }
countOccurrences(['constructor', 'constructor']); // { 'constructor': 2 }
```
