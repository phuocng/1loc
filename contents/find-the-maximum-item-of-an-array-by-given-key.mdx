title: Find the maximum item of an array by given key
updated: '2026-10-29'
---

**JavaScript version**

```js maxBy.js
const maxBy = (arr, key) => arr.reduce((a, b) => (a === undefined || b[key] > a[key] ? b : a), undefined);
```

**TypeScript version**

```ts maxBy.ts
const maxBy = <T extends Record<string, any>, K extends keyof T>(arr: T[], key: K): T | undefined => (
    arr.reduce<T | undefined>((a, b) => (a === undefined || b[key] > a[key] ? b : a), undefined)
);
```

**Example**

```js example.js
const people = [
    { name: 'Bar', age: 24 },
    { name: 'Baz', age: 32 },
    { name: 'Foo', age: 42 },
    { name: 'Fuzz', age: 36 },
];
maxBy(people, 'age'); // { name: 'Foo', age: 42 }
maxBy([], 'age'); // undefined
```
