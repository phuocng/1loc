title: Calculate the number of difference days between two dates
updated: '2026-10-29'
---

**JavaScript version**

```js diffDays.js
// `Math.round`: a daylight-saving change adds or removes an hour, which `Math.ceil` turned into an extra day
const diffDays = (date, otherDate) => Math.round(Math.abs(date - otherDate) / (1000 * 60 * 60 * 24));
```

**TypeScript version**

```ts diffDays.ts
const diffDays = (date: Date, otherDate: Date): number =>
    Math.round(Math.abs(date.valueOf() - otherDate.valueOf()) / (1000 * 60 * 60 * 24));
```

**Examples**

```js examples.js
diffDays(new Date('2014-12-19'), new Date('2020-01-01')); // 1839
diffDays(new Date('2020-01-01'), new Date('2020-01-01')); // 0
```
