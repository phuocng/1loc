title: Validate a Gregorian date
updated: '2026-10-29'
---

**JavaScript version**

```js
// `m`: the month (zero-based index)
// `d`: the day
// `y`: the year
const isValidDate = (m, d, y) => 0 <= m && m <= 11 && 0 < y && y < 32768 && 0 < d && d <= new Date(y, m + 1, 0).getDate();
```

**TypeScript version**

```ts isValidDate.ts
const isValidDate = (m: number, d: number, y: number): boolean =>
    0 <= m && m <= 11 && 0 < y && y < 32768 && 0 < d && d <= new Date(y, m + 1, 0).getDate();
```

**Examples**

```js examples.js
isValidDate(1, 29, 2024); // true
isValidDate(1, 29, 2023); // false
isValidDate(1, 30, 2024); // false
isValidDate(3, 31, 2024); // false
```
