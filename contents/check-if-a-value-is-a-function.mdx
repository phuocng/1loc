**JavaScript version**

```js isFunction.js
const isFunction = (v) => typeof v === 'function';
```

**Examples**

```js examples.js
isFunction(function () {}); // true
isFunction(function* () {}); // true
isFunction(async function () {}); // true
isFunction(class {}); // true
isFunction(Promise.resolve()); // false
```
