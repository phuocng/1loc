title: Get all siblings of an element
updated: '2026-10-29'
---

**JavaScript version**

```js siblings.js
const siblings = (ele) => (ele.parentNode ? [].slice.call(ele.parentNode.children).filter((child) => child !== ele) : []);
```

**TypeScript version**

```ts siblings.ts
const siblings = (ele: Node): Node[] =>
    ele.parentNode ? [].slice.call(ele.parentNode.children).filter((child) => child !== ele) : [];
```
