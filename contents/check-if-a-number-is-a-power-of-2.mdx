title: Check if a number is a power of 2
updated: '2026-10-29'
---

**JavaScript version**

```js isPowerOfTwo.js
const isPowerOfTwo = (n) => n > 0 && (n & (n - 1)) === 0;
```

**TypeScript version**

```ts isPowerOfTwo.ts
const isPowerOfTwo = (n: number): boolean => n > 0 && (n & (n - 1)) === 0;
```

**Examples**

```js examples.js
isPowerOfTwo(256); // true
isPowerOfTwo(129); // false
isPowerOfTwo(1); // true
isPowerOfTwo(0); // false
```
