title: Swap two array items
updated: '2026-10-29'
---

**JavaScript version**

```js swapItems.js
const swapItems = (a, i, j) => a.map((item, index) => (index === i ? a[j] : index === j ? a[i] : item));
```

**TypeScript version**

```ts swapItems.ts
const swapItems = <T,_>(a: T[], i: number, j: number): T[] => a.map((item, index) => (index === i ? a[j] : index === j ? a[i] : item));
```

**Example**

```js example.js
swapItems([1, 2, 3, 4, 5], 1, 4); // [1, 5, 3, 4, 2]
swapItems([1, 2, 3, 4, 5], 4, 1); // [1, 5, 3, 4, 2]
swapItems([0, 1, 2], 0, 2); // [2, 1, 0]
```
