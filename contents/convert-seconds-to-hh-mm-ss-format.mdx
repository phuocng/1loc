**JavaScript version**

```js formatSeconds.js
// `s` is number of seconds
const formatSeconds = (s) =>
    [parseInt(s / 60 / 60), parseInt((s / 60) % 60), parseInt(s % 60)].join(':').replace(/\b(\d)\b/g, '0$1');
```

**TypeScript version**

```ts formatSeconds.ts
const formatSeconds = (s: number): string => (
    [parseInt(`${s / 3600}`), parseInt(`${(s / 60) % 60}`), parseInt(`${s % 60}`)].join(':').replace(/\b(\d)\b/g, '0$1')
);
```

**Examples**

```js examples.js
formatSeconds(200); // 00:03:20
formatSeconds(500); // 00:08:20
formatSeconds(90061); // 25:01:01
```
