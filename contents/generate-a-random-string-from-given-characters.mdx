title: Generate a random string from given characters
updated: '2026-10-29'
---

**JavaScript version**

```js generateString.js
// `crypto.getRandomValues` is available in browsers and Node.js 19+
const generateString = (length, chars) =>
    Array.from(crypto.getRandomValues(new Uint32Array(length)), (n) => chars[n % chars.length]).join('');
```

**TypeScript version**

```ts generateString.ts
const generateString = (length: number, chars: string): string =>
    Array.from(crypto.getRandomValues(new Uint32Array(length)), (n) => chars[n % chars.length]).join('');
```

**Examples**

```js examples.js
generateString(10, '0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ');
```
