title: Generate a random string with given length
updated: '2026-10-29'
---

**JavaScript version**

```js generateString.js
// `crypto.getRandomValues` is available in browsers and Node.js 19+
const generateString = (length) =>
    Array.from(crypto.getRandomValues(new Uint32Array(length)), (n) => (n % 36).toString(36)).join('');
```

**TypeScript version**

```ts generateString.ts
const generateString = (length: number): string =>
    Array.from(crypto.getRandomValues(new Uint32Array(length)), (n) => (n % 36).toString(36)).join('');
```
