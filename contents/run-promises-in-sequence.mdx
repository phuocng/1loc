title: Run Promises in sequence
updated: '2026-10-29'
---

**JavaScript version**

```js run.js
// `tasks` is an array of functions; each returns a `Promise` when called
const run = (tasks) => tasks.reduce((p, c) => p.then((rp) => c().then((rc) => [...rp, rc])), Promise.resolve([]));
```

**TypeScript version**

```ts run.ts
const run = (tasks: (() => Promise<any>)[]): Promise<any[]> =>
    tasks.reduce((p, c) => p.then((rp) => c().then((rc) => [...rp, rc])), Promise.resolve([] as any[]));
```

**Examples**

```js examples.js
const tasks = [() => fetch('/a'), () => fetch('/b')];
run(tasks).then((results) => {
    // `results` is an array of results in the same order; `/b` is requested only after `/a` settles
});
```
