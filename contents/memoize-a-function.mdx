**JavaScript version**

```js memoize.js
const memoize = (fn) =>
    (
        (cache = new Map()) =>
        (arg) =>
            cache.has(arg) ? cache.get(arg) : cache.set(arg, fn(arg)).get(arg)
    )();
```

**Examples**

```js examples.js
// Calculate Fibonacci numbers
const fibo = memoize((n) => (n <= 2 ? 1 : fibo(n - 1) + fibo(n - 2)));

fibo(1); // 1
fibo(2); // 1
fibo(3); // 2
fibo(4); // 3
fibo(5); // 5
fibo(6); // 8

// Falsy results are cached too
let calls = 0;
const isEven = memoize((n) => (calls++, n % 2 === 0));
isEven(3); // false
isEven(3); // false
calls; // 1
```
