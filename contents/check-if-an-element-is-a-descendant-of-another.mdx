title: Check if an element is a descendant of another
updated: '2026-10-29'
---

**JavaScript version**

```js isDescendant.js
const isDescendant = (child, parent) => child !== parent && parent.contains(child);
```

**TypeScript version**

```ts isDescendant.ts
const isDescendant = (child: Node, parent: Node): boolean => child !== parent && parent.contains(child);
```

**Examples**

```js examples.js
isDescendant(document.body, document.documentElement); // true
isDescendant(document.body, document.body); // false
```
