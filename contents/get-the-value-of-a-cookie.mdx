title: Get the value of a cookie
updated: '2026-10-29'
---

**JavaScript version**

```js cookie.js
const cookie = (name) => {
    const parts = `; ${document.cookie}`.split(`; ${name}=`);
    return parts.length > 1 ? parts.pop().split(';').shift() : null;
};
```

**Examples**

```js examples.js
cookie('_ga'); // GA1.2.825309271.1581874719
cookie('missing'); // null
```
