title: Check if a string contains whitespace
updated: '2026-10-29'
---

**JavaScript version**

```js containsWhitespace.js
const containsWhitespace = (str) => /\s/.test(str);
```

**TypeScript version**

```ts containsWhitespace.ts
const containsWhitespace = (str: string): boolean => /\s/.test(str);
```

**Examples**

```js examples.js
containsWhitespace('hello world'); // true
containsWhitespace('hello'); // false
```
